# Rename to Drover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app becomes Drover (`dev.cuongtransc.drover`) everywhere it names itself, with a new logo and a one-time copy of the user's state from the old identifier.

**Architecture:** Mechanical renames in config, Rust, TypeScript and shell; one new shell script (`scripts/migrate-id.sh`) with its own test wired into `mise run test`; a new SVG logo turned into icons by `mise run gen:icons`. No runtime behaviour changes except the names.

**Tech Stack:** Tauri 2, Rust, React/TypeScript (vitest), POSIX sh, mise.

**Spec:** `docs/superpowers/specs/2026-10-12-rename-drover-design.md`

## Global Constraints

- New names, exactly: product `Drover` / `Drover Dev`; identifier `dev.cuongtransc.drover` / `dev.cuongtransc.drover.dev`; Cargo package `drover`, lib `drover_lib`; npm package `drover`; runtime dir `drover` / `drover-dev`; signing identity `Drover Local Signing`; env vars `DROVER_SIGN_IDENTITY`, `DROVER_SIGN_KEYCHAIN`, `DROVER_SIGN_KEYCHAIN_PASSWORD`, `DROVER_SSH_TEST`; integration sessions `drover-test-*`; installed bundle `/Applications/Drover.app`.
- Old identifier, for the migration only: `dev.cuongnb.herdrapp` (and `.dev`). No other file keeps it.
- "herdr" lowercase always means the multiplexer and is never renamed: `src-tauri/src/herdr/`, `FakeHerdr`, `syncSeenToHerdr`, `HerdrPathEdit`, `herdrPath`, `herdrCall`, CLI calls to `herdr`.
- Kept as written: everything under `docs/superpowers/` and `docs/adr/` dated before 2026-10-12; test fixtures whose Workspace label or folder is `herdr-app` (`src/**/*.test.*`, `src/docs/uiMap.capture.tsx`, `src-tauri/src/git.rs`, `src-tauri/src/complete/files.rs`, `src-tauri/src/transport/ssh.rs` tests).
- Shell scripts stay POSIX `sh` (macOS zsh/bash and Linux bash compatible), messages prefixed with the script's name and a colon (`migrate-id: …`), like `sign-setup:`.
- Every commit runs the repo's pre-commit gate; never `--no-verify` on a commit with code.

## Review Focus

- The user's app running during migration: copying a live WebKit folder can tear localStorage; the script must refuse (Task 4 test "refuses while an app runs").
- Running the migration twice, or after the new app has already started once: must never overwrite the new state (Task 4 test "keeps a target that exists").
- An old folder that does not exist (e.g. no `Caches`, no dev build ever run): must be skipped silently, not fail (Task 4 test "skips what is missing").
- Paths with spaces (`Application Support`): every path quoted (Task 4 test covers `Application Support`).
- A reinstall while Drover is open: `app:install` must not run the migration once the new state exists (Task 4 Step 6 condition).

### Task 4: One-time state migration

**Files:**
- Create: `scripts/migrate-id.sh`
- Create: `scripts/migrate-id.test.sh`
- Modify: `mise.toml` (new tasks `app:migrate-id`, `test:migrate`; `test` depends on `test:migrate`; `app:install` and `app:install:release` run the migration first when needed)

**Interfaces:**
- Consumes: binary name `drover` (Task 1); old binary name `herdr-app`.
- Produces: `scripts/migrate-id.sh` — no arguments; reads `HOME`; reads `MIGRATE_ID_APPS` (space-separated process names, default `herdr-app drover`); exit 0 when done (copied or skipped), exit 1 when an app runs.

Behaviour (from the spec): for each suffix `""` and `.dev`, and each item `Library/WebKit/<id>`, `Library/Application Support/<id>`, `Library/Caches/<id>`, `Library/Preferences/<id>.plist`, with `<id>` = `dev.cuongnb.herdrapp<suffix>` → `dev.cuongtransc.drover<suffix>`:
- old missing → nothing printed;
- new exists → `migrate-id: kept <new path relative to HOME> (already there)`;
- else copy with `cp -Rp` → `migrate-id: copied <old rel> -> <new rel>`.
Before anything: if `pgrep -x` finds any name in `MIGRATE_ID_APPS` → `migrate-id: quit <name> first` on stderr, exit 1, nothing copied. Old items are never modified or removed.

- [ ] **Step 1: Write the test**

```sh
#!/bin/sh
# Tests for migrate-id.sh on a throwaway HOME. Run by `mise run test:migrate`.
set -u
here=$(cd "$(dirname "$0")" && pwd)
tmp=$(mktemp -d)
cleanup() { [ -n "${pid:-}" ] && kill "$pid" 2>/dev/null; rm -rf "$tmp"; }
trap cleanup EXIT

fails=0
check() { # check <name> <command...>
  name=$1; shift
  if "$@"; then echo "ok   $name"; else echo "FAIL $name"; fails=$((fails + 1)); fi
}

old=dev.cuongnb.herdrapp
new=dev.cuongtransc.drover
fresh_home() {
  rm -rf "$tmp/home"
  mkdir -p "$tmp/home/Library/WebKit/$old/WebsiteData/LocalStorage" \
    "$tmp/home/Library/Application Support/$old" "$tmp/home/Library/Preferences"
  echo ls >"$tmp/home/Library/WebKit/$old/WebsiteData/LocalStorage/db"
  echo '{"m":1}' >"$tmp/home/Library/Application Support/$old/machines.json"
  echo plist >"$tmp/home/Library/Preferences/$old.plist"
}
run() { HOME="$tmp/home" MIGRATE_ID_APPS="migrate-test-$$" "$here/migrate-id.sh" >"$tmp/out" 2>&1; }

fresh_home
check "copies: exit 0" run
check "copies localStorage" grep -q ls "$tmp/home/Library/WebKit/$new/WebsiteData/LocalStorage/db"
check "copies Application Support" grep -q '"m":1' "$tmp/home/Library/Application Support/$new/machines.json"
check "copies the plist" grep -q plist "$tmp/home/Library/Preferences/$new.plist"
check "keeps the old folders" test -f "$tmp/home/Library/Application Support/$old/machines.json"
check "says what it copied" grep -q "migrate-id: copied Library/Application Support/$old -> Library/Application Support/$new" "$tmp/out"
check "skips what is missing (no Caches, no .dev)" sh -c "! test -e '$tmp/home/Library/Caches/$new' && ! grep -q '\.dev' '$tmp/out'"

fresh_home
mkdir -p "$tmp/home/Library/Application Support/$new"
echo '{"m":2}' >"$tmp/home/Library/Application Support/$new/machines.json"
check "keeps a target that exists: exit 0" run
check "keeps a target that exists: content" grep -q '"m":2' "$tmp/home/Library/Application Support/$new/machines.json"
check "keeps a target that exists: says so" grep -q "migrate-id: kept Library/Application Support/$new (already there)" "$tmp/out"

fresh_home
cp /bin/sleep "$tmp/migrate-test-$$"
"$tmp/migrate-test-$$" 30 &
pid=$!
sleep 0.2
check "refuses while an app runs: exit 1" sh -c "! HOME='$tmp/home' MIGRATE_ID_APPS='migrate-test-$$' '$here/migrate-id.sh' >'$tmp/out' 2>&1"
check "refuses while an app runs: says which" grep -q "migrate-id: quit migrate-test-$$ first" "$tmp/out"
check "refuses while an app runs: copies nothing" test ! -e "$tmp/home/Library/WebKit/$new"

[ "$fails" -eq 0 ] && echo "migrate tests: all passed" || { echo "migrate tests: $fails failed"; exit 1; }
```
