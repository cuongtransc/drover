# User guide

How to use the features that go beyond "open a pane". Names of what is on screen follow the UI surfaces table
in [CONTEXT.md](../../CONTEXT.md); a numbered picture of them is [docs/design/ui-map.html](../design/ui-map.html).

| Guide | When you need it |
|---|---|
| [01 · Files](01-files.md) | Read a Workspace's files next to its agents, find one, see what changed, move files to and from the Mac |
| [02 · Protect a pane](02-protect-pane.md) | Keep an important pane (an orchestrator) from being closed by mistake |
| [03 · Fork a Claude session](03-fork-session.md) | Start a second session from the same conversation, in the same folder or its own worktree |
| [04 · Ask on the side with /btw](04-side-questions.md) | Ask a working Claude a question without interrupting or steering it |
| [05 · Edit your last message](05-edit-last-message.md) | Take back the message you just sent, change it and send it again |

Which of Fork and `/btw` to use day to day, next to lanes and briefs, is part of the operating guide in
ct-workstation (`docs/agents/03-operating-guide.md` §9). A guide is updated in the same PR as the feature it describes.
